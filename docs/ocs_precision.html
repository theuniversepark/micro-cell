1-1. UNS 설계 개념 — FacOS 연계

UNS(Unified Namespace) — 중심 통로는 MQTT 5, 설비 접점은 OPC UA

기준은 「UNS 기반 FacOS의 통신 방식 검토: OPC UA와 MQTT의 역할 분담 및 병행 구성」(캠틱, 2026-11-09) [U1]임. FacOS UNS의 중심 통로는 MQTT 5 + Sparkplug B + ISA-95 토픽, OPC UA는 설비 접점에 둠. 정밀조립존에서는 Edge Gateway가 설비 OPC UA를 읽어 UNS로 올리는 유일한 입구(L1.5)가 되고, Local Server의 운영 SW는 설비에 직접 접속하지 않고 존 로컬 UNS 브로커만 구독함. 토픽은 메타팩토리와 같은 camtic/metafactory/main/… 트리를 씀(셀 ID 표기는 예시). 이 절은 설계안이며 세부1(FacOS)과 합의된 사양이 아님.
